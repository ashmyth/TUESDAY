# AGENTS

## Design Context

Before any UI/design work on this repo, read the project design system:

- **PRODUCT.md** — strategic layer: register (product), users, purpose, brand personality, anti-references, design principles (evidence before verdict; stealth not spectacle; guard the operator's attention; everything reversible; air-gapped by principle).
- **DESIGN.md** — visual layer: the "Air-Gap Ops Room" system, Signal Palette (Emerald/cyan/purple/crimson/amber), Plus Jakarta Sans + JetBrains Mono, elevation and No-Ghost rule, machined & tactile components.
- **.impeccable/design.json** — machine-readable tokens, ramps, motion, breakpoints, and renderable component snippets.

Two apps share one system: **Sentinel** (`sentinel/`) leads with emerald (defense); **RedTeam** (`redteam/`) leads with crimson (offense). Keep both on the same token architecture.
